# Примеры HTML для админ-рассылки

**Где хранится «настоящий» шаблон:** в таблице `email_templates` — создаётся и редактируется в интерфейсе **Admin → Email** после применения миграции с почтовыми таблицами.

**Зачем эта папка:** готовые фрагменты (тема + HTML), которые можно скопировать в форму создания шаблона. Письма уходят через Resend; подстановки — см. `@entities/email-template` (`{{name}}`, `{{email}}`, …, `{{site_url}}`).

**Ссылки на сайт в письме:** используйте `{{site_url}}` — он подставляется на отправке из `getPublicSiteUrl()` (`NEXT_PUBLIC_SITE_URL` / Vercel). Пример ссылки на галерею: `{{site_url}}/ru/gallery` (RU) и `{{site_url}}/gallery` (EN, локаль по умолчанию без префикса).
